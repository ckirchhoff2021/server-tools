# Server Tools

独立可部署的 AI 模型 HTTP 服务工具集，将各类模型封装为 REST API 供 Agent 系统或其他应用调用。

## 工具列表

| 工具 | 端口 | 说明 |
|------|------|------|
| [timesfm3](timesfm3/) | 8333 | Google TimesFM 3.0 时间序列预测服务，支持单变量/多变量预测、分位数输出 |

## 通用使用流程

1. 进入对应工具目录
2. 安装依赖并下载模型权重
3. 启动 HTTP 服务
4. 通过 HTTP API 或客户端 SDK 调用

## 添加新服务

每个子目录对应一个独立服务，应包含：
- 服务启动脚本（HTTP server）
- 客户端调用示例
- README 文档（依赖、启动方式、API 说明）
